Este documento describe el modelo de datos mínimo necesario para alimentar todas las pantallas del prototipo. El sistema gestiona el ciclo completo de proyectos de carpintería: desde la solicitud comercial hasta la garantía postventa. La base de datos es Cloudflare D1 (SQLite edge) con 20 tablas organizadas en 6 dominios de negocio.
